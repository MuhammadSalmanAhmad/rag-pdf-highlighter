## `GET /`

Health check.

**Response**

```json
{ "status": "ok the app is running" }
```

## `POST /highlight`

Download a PDF from a URL, highlight the given chunks, and return the annotated PDF.

### Request body

| Field | Type | Description |
|-------|------|-------------|
| `pdf_url` | `string` | URL of the PDF to highlight |
| `documents` | `array` | List of `{ page_content, metadata }` objects |
| `documents[].page_content` | `string` | Text chunk to locate and highlight |
| `documents[].metadata.page` | `int` | Zero-indexed page number |

### Example

```bash
curl -X POST http://localhost:8000/highlight \
  -H "Content-Type: application/json" \
  -d '{
    "pdf_url": "https://example.com/report.pdf",
    "documents": [
      {
        "page_content": "Text to highlight",
        "metadata": {"page": 0}
      }
    ]
  }' \
  --output highlighted.pdf
```

### Response

- **Content-Type:** `application/pdf`
- **Body:** Highlighted PDF file (`highlighted.pdf`)

### Errors

| Status | Meaning |
|--------|---------|
| `400` | Invalid PDF URL, download failure, or highlighting error |
| `422` | Invalid request body |
| `500` | Unexpected server error |
